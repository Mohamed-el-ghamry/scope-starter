# scope-starter

Template for projects built with the SCOPE method (Scope, Chart, Outline, Program, Engineer). Holds config and markdown only; the stack is chosen per project in `docs/02-chart.md`.

Contents: `CLAUDE.md`, `.claude/` (rules, Bash guard hook, settings), `.gitignore`, `docs/`.

Use: copy this folder to a new project, fill the Project section of `CLAUDE.md`, add `docs/PROJECT_CONTEXT.md`.
